# Check this computer — student guide

## What this is

"Check this computer" is a quick, optional check that helps prevent
technical interruptions on exam day. It confirms your computer, Tether
Secure Browser installation, and permissions (camera, microphone) are
ready **before** you sit a final examination — not during it.

Running the check is **not** the same as taking your exam. It never
creates an exam attempt, and passing it does not by itself let you skip
any step your exam actually requires when you start it for real.

## Privacy

- No photo or video is ever saved.
- No audio recording is ever saved.
- Your camera and microphone are only turned on while the check is
  running, and only after you select "Run system check" — never
  automatically.
- The only thing saved is a short pass/warning/blocked result per item
  (for example, "camera: ready"), your Tether Secure Browser version if
  detected, and your operating system — never an image, a recording, or
  any other device information.

## How to run it

1. Go to `/student/system-check`, or select **Check this computer** from
   your dashboard, the Tether launch page, or your final exam's
   preparation screen.
2. Read the short explanation and privacy notice.
3. Select **Run system check**. Each item runs one at a time and shows
   its result as soon as it finishes.
4. If an item needs attention, a short plain-language fix is shown
   underneath it (for example, "Disconnect the additional display and
   retry").
5. Select **Retry check** to run everything again after making a fix.

## What the results mean

- **Ready** — this item is working correctly.
- **Needs attention** — something should be reviewed before your exam,
  but it may not stop you from continuing (for example, a slightly slow
  network connection).
- **Cannot continue** — this item must be fixed before this computer is
  ready for a final examination.
- **Not checked** — this item could not be checked here. A few items
  (your Tether Secure Browser session, version, display setup, and
  secure browser connection) can only be checked from inside Tether
  Secure Browser — open it from this page to check those.

## A complete check needs Tether Secure Browser

In an ordinary browser (Chrome, Edge, etc.) this page can confirm you're
signed in and that the server is reachable, but it cannot fully confirm
your display setup, camera, or the secure browser itself. Select **Open
Tether Secure Browser** to run the complete check.

## Before a final examination

Your final exam's preparation screen shows your most recent check
result, when it was completed, and when it expires. If your institution
requires a current check before starting a final examination, the page
will tell you and link you back here — running the check again only
takes a minute.

Even after a successful check, your exam's own verification still runs
again when you actually start it. This check is there to catch problems
early, not to replace that.
